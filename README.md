

Project Name: Anjana Store Annual Report 2022 (Excel Dashboard)

Project Overview:
An interactive Excel dashboard built to analyze the annual sales performance of Anjana Store for the year 2022. This project helps stakeholders track revenue trends, customer demographics, regional performance, and order fulfillment status.

Key Features & Insights:

Sales & Orders Trend: Analyzed monthly sales volume and total order counts.

Customer Demographics: Evaluated sales distribution across Gender (Male vs Female) and Age Groups (Adult, Senior Citizen, Teenager).

Regional Analysis: Highlighted the Top 7 performing states by sales volume.

Sales Channels: Tracked performance across multiple e-commerce and retail channels (Ajio, Amazon, Flipkart, Meesho, Myntra, Nalli, Others).

Order Status Breakdown: Monitored delivery status including Delivered, Cancelled, Refunded, and Returned orders.

Tools Used:

Microsoft Excel (Pivot Tables, Pivot Charts, Slicers, Dashboard Design)
